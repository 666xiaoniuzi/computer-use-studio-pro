# Computer Use Studio Pro 隐私政策

**版本：2026.08**　**生效日期：您点击同意之日**

本政策说明本产品如何收集、使用和保护您的信息。我们遵循最小必要原则，仅收集实现授权验证所必需的信息。

## 1. 我们收集的信息

| 信息 | 内容 | 是否包含个人信息 |
|---|---|---|
| 机器码 | v2 根据操作系统稳定设备标识生成 SHA-256 匿名哈希；旧授权按原 v1（系统标识、CPU、网卡）兼容校验，形如 `CUSP-XXXX-XXXX-...` | 否（哈希后不可还原为原始标识） |
| 同意记录 | 您同意本政策及《用户协议》的版本号与时间 | 否 |
| 订单信息 | 您在购买平台（如闲鱼）上的昵称与订单号 | 仅您主动通过平台聊天提供 |
| 使用过程数据 | 软件运行中产生的截图、日志、任务文件及脱敏里程碑检查点 | 仅保存在您自己的电脑上，软件不会上传 |
| 远程协助会话 | 您主动发起时产生的第三方远程连接（连接时间、时长、流量由远程软件自身记录） | 由您选择的第三方远程软件按其隐私政策处理；卖家不记录、不保存协助内容 |

## 2. 我们如何使用信息

- **机器码**：仅用于生成和校验您的授权文件，实现单机绑定、防止盗版；
- **同意记录**：用于证明您已同意协议，并仅在协议更新时要求重新确认；
- **订单信息**：用于核对购买身份、售后（换机重签、补发授权文件）。

## 3. 信息的存储与传输

1. **本产品运行时不联网、不主动上传任何数据**。机器码、同意记录、签名吊销清单和脱敏检查点仅保存在您本机（`%LOCALAPPDATA%\ComputerUseStudioPro\` 及产品目录内）；吊销清单由您手动安装或随软件更新获得；
2. 您将机器码通过购买平台聊天发送给卖家，是您主动、自愿的行为，且机器码本身不含个人信息；
3. 卖家将机器码与订单号保存在自己的本地设备中，仅用于签发授权与售后，**不会出售或提供给第三方**；
4. **远程协助**：如您选择卖家远程协助安装激活，您需自行安装并启用第三方远程桌面软件（如 ToDesk、向日葵）并向卖家提供临时连接码；协助期间您设备屏幕内容会传输给作为操控方的卖家，仅用于完成安装激活，卖家不记录、不保存其中任何内容；协助结束后请您断开连接并作废连接码。

## 4. 我们不收集的信息

本产品不收集：姓名、身份证号、手机号、通讯录、位置、浏览器记录、您操作对象电脑上的任何文件内容（操作过程仅在您本机发生）。任何情况下，我们都建议您**不要通过平台聊天发送密码、验证码、支付信息**；此类信息即使出现在聊天中也请自行修改或关闭相关会话。

## 5. 您的权利

1. **查询与更正**：您可随时向卖家查询与您订单相关的签发记录；
2. **删除**：卸载本产品并删除 `%LOCALAPPDATA%\ComputerUseStudioPro\` 目录即清除本机全部记录；您可要求卖家删除您的签发记录（删除后授权将无法恢复）；
3. **撤回同意**：删除上述目录即撤回同意，本产品将无法运行；
4. **投诉**：如认为权益受损，可联系卖家或向有关监管机构投诉。

## 6. 政策更新

本政策更新后，本产品会重新提示您确认；未确认前产品将暂停运行。
