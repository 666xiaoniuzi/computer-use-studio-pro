# Computer Use Studio Pro 安装与激活说明（买家版）

感谢购买！按下面 4 步完成安装和激活。遇到问题随时联系卖家。

> **不想自己动手？** 可联系卖家选择"远程协助安装激活"：您只需下载安装包、同意协议并提供远程连接码，其余由卖家在您屏幕上完成，您可全程查看、随时中断。自行安装请继续按本说明操作。

## 0. 使用前提

- Windows 10/11 电脑（一台授权绑定一台电脑）；
- 已安装 **Node.js**（LTS 版，https://nodejs.org 下载 `.msi` 双击安装，自动加入 PATH）。装好后在终端输入 `node --version` 能显示版本号即可，**无需手动配置环境变量**；
- 已安装 [Codex CLI](https://github.com/openai/codex)（`codex` 命令可用，本产品依赖它运行；Codex CLI 本身也依赖 Node.js）；
- 远程任务已安装 ToDesk、向日葵、RustDesk、AnyDesk、TeamViewer 或等价可见远程桌面客户端。

## 1. 安装

推荐把压缩包解压到任意临时目录，在解压后的 `computer-use-studio-pro` 目录打开 PowerShell 并运行：

```powershell
.\install.ps1 -Agree
```

脚本会原子安装完整目录、保留失败回滚，并显示稳定机器码 v2。手动安装时，把压缩包里的 `computer-use-studio-pro` 文件夹**整个**解压到：

```
C:\Users\你的用户名\.codex\skills\
```

解压后应能看到：`C:\Users\你的用户名\.codex\skills\computer-use-studio-pro\SKILL.md`。

## 2. 同意协议 + 获取机器码

首次使用前，请先阅读本文件夹里的《用户协议.md》和《隐私政策.md》。

- **用第 1 步一键安装（`.\install.ps1 -Agree`）的**：安装输出里已直接显示机器码，本步可跳过。
- **手动解压安装的**：在终端（PowerShell 或 CMD）先进入脚本目录，再运行短命令：

```powershell
cd "$env:USERPROFILE\.codex\skills\computer-use-studio-pro\adapters\codex\scripts"
node agree_consent.mjs 同意
```

运行后会自动显示两样东西：

1. 确认"已完成同意确认"；
2. **您的机器码**（`CUSP-` 开头的一串），如下：
   ```
   您的机器码是：
     CUSP-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX
   ```

## 3. 把机器码发给卖家

把上面显示的机器码整段复制发给卖家。卖家会回给您一个 `license.json` 文件。

> 之后想再查机器码（比如重装后、或给新电脑）：在脚本目录运行
> `node agree_consent.mjs --status`（或重新运行 `.\install.ps1 -Agree`），它会再次显示机器码。

## 4. 激活授权（一条命令搞定）

收到 license.json 后，任选一种方式：

**方式一（推荐）**：还保留着解压出来的技能目录的话，进入该目录，一条命令完成"校验签名/设备/有效期 + 原子安装 + 诊断"：

```powershell
.\install.ps1 -License "C:\Users\你的用户名\Downloads\license.json" -Doctor
```

**方式二**：解压目录已删也行，先进入已安装的脚本目录，再用短命令：

```powershell
cd "$env:USERPROFILE\.codex\skills\computer-use-studio-pro\adapters\codex\scripts"
node manage_license.mjs activate "C:\Users\你的用户名\Downloads\license.json"
node manage_license.mjs doctor
```

工具会先验证签名、机器码、授权类型、版本、有效期和本地签名吊销清单，再原子写入推荐位置。诊断全部通过后**重启 Codex** 即可正常使用。

手动放置仍支持（激活工具会自动完成，通常不需要）：把 license.json 放到下面**任一**位置：

1. `C:\Users\你的用户名\AppData\Local\ComputerUseStudioPro\license.json`（文件夹不存在就手动新建）
2. `C:\Users\你的用户名\.codex\skills\computer-use-studio-pro\license.json`

## 常见问题

- **提示"授权与当前设备不匹配"**：说明这台电脑不是签发时对应的电脑。请把新电脑的机器码发给卖家重新签发。
- **重装系统后机器码变了**：同样把新机器码发给卖家重签。
- **授权文件丢了**：找卖家补发，不用重新购买。
- **提示需要同意协议**：说明还没做同意确认，在脚本目录运行 `node agree_consent.mjs 同意`（或重新运行 `.\install.ps1 -Agree`）即可。
- **换电脑了**：授权只绑定一台电脑，换机后把新机器码发给卖家重新签发即可（按协议约定）。
